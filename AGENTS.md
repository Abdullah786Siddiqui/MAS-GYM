# MAS GYM Developer & AI Instructions

## Design System & Theme Directives
All UI development in this repository follows the strict **Emerald & Teal + Zinc** design system.
Read and follow [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) for color tokens, contrast rules, and component markup patterns.

### Quick Tokens Reference:
- **Primary Brand**: `#10b981` (`emerald-500`)
- **Accent**: `#14b8a6` (`teal-500`) / `#0d9488` (`teal-600`)
- **Brand Gradient**: `bg-gradient-to-r from-emerald-500 to-teal-600`
- **Dark Mode Background**: `#09090b` (`bg-zinc-950`)
- **Dark Mode Cards**: `#18181b` (`bg-zinc-900`)
- **Light Mode Background**: `#fafafa` (`bg-zinc-50`)
- **Light Mode Cards**: `#ffffff` (`bg-white`)
- **Page Loader**: Centered animated dumbbell vector loader (`PageLoader.vue`) on every Inertia page change.
